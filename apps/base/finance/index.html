Findash — long-term stock dashboard

First version, reserved endpoint. Not analytics-ready yet.

Status

  • Hostname finance.passer.lan lives — routed through the Envoy Gateway on 192.168.178.240.
  • Container image for the Dash app is not built yet, so this is a placeholder page.
  • The upstream source database that feeds prices is not configured yet either — the app supports a seed-demo synthetic dataset for development in the meantime.

What Findash is

A modular finance-analysis dashboard for a configurable list of instruments (indices, ETFs, commodities). Two modes: historical exploration and probabilistic forecasts from nightly batch runs. Research and analysis only — not investment advice.

What still needs to happen for the real app to boot

  1. Build the container image from ~/gh/longterm-stock-dashboard-py/docker/Dockerfile and push it to a registry the cluster can pull from (typically ghcr.io/hschoss/findash:<tag>).
  2. Point the findash-app Deployment's image: at that tag — the rest of the wiring (namespace, Postgres via CNPG, Service, HTTPRoute, DB migrations job) is already in the repo under apps/base/finance/.
  3. Seed with findash seed-demo so the dashboard has something to draw until the source database is wired up.

Where the code lives
